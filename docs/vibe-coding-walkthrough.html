Environment Setup

Let me break down what "environment" means in plain English:

How to Activate

Before running anything, you need to "activate" the virtual environment:

PowerShell:
.\.venv\Scripts\Activate.ps1

Bash (macOS/Linux):
source .venv/bin/activate

Once activated, your terminal shows (.venv) at the start. This tells you the sandbox is active.

Pro Tip: Always check for (.venv) in your terminal prompt. If it's not there, you're not in the sandbox and things will break.

Testing Setup

Tests are automated checks that make sure your code works the way you expect. Here's the flow:

1

Run Tests from Terminal

Make sure you're in the project root and the venv is active, then type pytest

2

Test Discovery

pytest looks in the tests/ folder and finds all files starting with test_

3

Execution

Each test runs automatically. Tests check that your code behaves the way you expect.

4

Results

You get a summary: how many passed, how many failed, how long it took.

Your Test Files

File What It Tests
tests/unit/test_foundation.py That imports work and config loads correctly
tests/integration/test_environment_ready.py That the whole environment is set up and ready

Running Things (Simple Examples)

Example 1: Activate the Virtual Environment

This is step zero. Do this first, every time.

PowerShell:
.\.venv\Scripts\Activate.ps1

You should see:
(.venv) C:\path\to\assignment3>

The (.venv) at the start means you're in the sandbox. Now you can run Python commands.

Example 2: Run All Tests

pytest

Output:
6 passed in 14.78s ✓

This means all 6 tests passed.

Example 3: Run Tests with Verbose Output

Want to see which tests ran individually?

pytest -v

Output:
tests/unit/test_foundation.py::test_imports_work PASSED
tests/integration/test_environment_ready.py::test_environment_is_ready_for_future_development PASSED
...
6 passed in 14.78s

Example 4: Health Check

Quick check that everything is wired up correctly:

python run.py --health-check

Output:
Python version: 3.11.9
Environment: development
Log level: INFO
Health check passed: the project foundation is ready for incremental development.
Remember: Always run these commands from the project root folder, with (.venv) visible in your terminal prompt.
